# Инструкции для ИИ-агентов

## Сборка прошивки

- Всегда запускай сборку в интерактивном терминале (`tty: true`), чтобы
  пользователь мог наблюдать процесс.
- Используй 15 параллельных задач: `-j 15`.
- После завершения успешной сборки укажи ссылку на созданную прошивку и
  использование Flash и RAM из вывода PlatformIO. Для окружения
  `esp32c3_4MB_wifi` формат отчёта:

  ```md
  Прошивка: [firmware.bin](/home/devz/3d/ESP3D/.pioenvs/esp32c3_4MB_wifi/firmware.bin)

  Память: Flash <процент>, RAM <процент>.
  ```
